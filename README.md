# 🌈 Mood Selector App

A colorful and interactive web app that lets you choose your mood, express your feelings, and save memories! Whether you're feeling **happy**, **sad**, or **excited**, this app responds with a beautiful background, a sweet message, and a notepad to journal your emotions.

---

## ✨ Features

- 🎨 **Big emoji buttons** for selecting moods: Happy 😊, Sad 😢, Excited 🤩
- 🌈 **Gradient background transitions** based on mood
- 📝 **Mood notepad** opens to let users write about their feelings
- 💾 **Saves memories** locally with mood, note, and timestamp
- 📚 **View all past notes** anytime for reflection or inspiration

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/mood-selector.git
cd mood-selector
````

### 2. Install dependencies

Make sure you have Flask installed:

```bash
pip install flask
```

### 3. Run the app

```bash
python app.py
```

Visit: [http://localhost:5000](http://localhost:5000)
